pyfantastat
===========

A Python library for Italian fantasy football (Fantacalcio) league management —
parse league calendars and lineup exports, compute standings with full tiebreaker
logic, run analytics, and estimate ranking probabilities via Monte Carlo simulation.

.. note::

   **Disclaimer:** pyfantastat is an independent, community-developed library. It is
   not affiliated with, sponsored by, or endorsed by `Fantacalcio.it <https://www.fantacalcio.it/>`_.
   The parsers expect Excel files that can be exported from the Fantacalcio.it platform;
